# Iterra-web

ระบบรับงานครบวงจรสำหรับบริษัทรับเขียนเว็บ ทำระบบ และอบรม — ตั้งแต่ขายงานจนถึงแบ่งผลประโยชน์

## ขั้นตอนในระบบ

1. **งานขาย** — ฝ่ายขายบันทึก Requirement → ระบบเรียก Claude API แตกรายการงาน ประเมิน man-day ตามตำแหน่ง ระยะเวลา และคำนวณราคาจากอัตราค่าแรง → สร้างหน้า Demo ของระบบ → คะแนนความเป็นไปได้ก่อนรับงาน (เทคนิค / เวลา / งบ / กำลังคน) → ผู้ดูแลระบบปรับรายการและราคา → ออกใบเสนอราคา → ปิดการขาย ระบบออกสัญญาและใบแจ้งหนี้ตามงวด เมื่อรับชำระจะออกใบเสร็จรับเงิน
2. **จัดโครงสร้างโครงการ** — เปิดโครงการอัตโนมัติ แบ่ง % งานตาม 17 ตำแหน่ง สร้างงานย่อยตาม 6 ช่วง (Requirement → Support) พร้อมกำหนดวันและแจ้งเตือน
3. **ติดตามงาน** — อัปเดตสถานะและความคืบหน้ารายงาน แผนงานตามช่วง งานเลยกำหนด
4. **แบ่งผลประโยชน์** — มูลค่างาน − ต้นทุนตรง − คอมมิชชันฝ่ายขาย แล้วแบ่งบริษัท/ทีมตามสัดส่วนตำแหน่ง บันทึกการจ่ายได้
5. **รายรับรายจ่าย** — รายรับจากใบเสร็จบันทึกอัตโนมัติ บันทึกรายจ่ายรายโครงการหรือส่วนกลาง
6. **Dashboard** — ภาพรวมงานขาย โครงการ และการเงิน

## เริ่มใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป (ใช้ SQLite ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูล)

```bash
npm install
cp .env.example .env      # แก้ ADMIN_PASSWORD และใส่ ANTHROPIC_API_KEY
npm run dev               # เว็บ http://localhost:5173 · API http://localhost:4000
```

ใช้งานจริง:

```bash
npm run build && npm start   # เปิด http://localhost:4000
```

- รันครั้งแรกระบบสร้างบัญชีผู้ดูแลจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` (ถ้าไม่ตั้ง จะเป็น `admin@iterra.local` / `iterra-admin` — เปลี่ยนรหัสผ่านทันที)
- `TEAM_PASSWORD=รหัสผ่าน npm run seed:team` สร้างบัญชีทีมงานตัวอย่างไว้ทดลอง
- ถ้าไม่ตั้ง `ANTHROPIC_API_KEY` ระบบยังใช้ได้ โดยประเมินจากคำสำคัญและแสดงโครงหน้าจอ Demo พื้นฐานแทน
- ข้อมูลเก็บที่ `data/iterra.db` (สำรองไฟล์นี้)

## สิทธิ์ผู้ใช้

| สิทธิ์ | ทำได้ |
|---|---|
| ผู้ดูแลระบบ (admin) | ดูและแก้ไขได้ทั้งหมด รวมถึงแก้ราคา รับชำระ การเงิน จ่ายส่วนแบ่ง ตั้งค่า และเพิ่ม/แก้ไขสมาชิก (เมนู "สมาชิก") |
| ผู้ถือหุ้น / กรรมการ | ดูได้ทั้งหมด (Dashboard งานขาย โครงการ ผลประโยชน์ การเงิน) แต่แก้ไขไม่ได้ |
| ฝ่ายขาย | งานขายของตนเองทุกงาน — ไม่เห็น Dashboard โครงการ และผลประโยชน์ |
| พนักงาน | ขายงาน (งานขายของตนเอง) ดูโครงการ และอัปเดตงานของตนเอง |

## โครงสร้างโค้ด

- `server/` — Express API · `db.js` (schema) · `estimator.js` (ราคา/ความเป็นไปได้) · `ai.js` (Claude API) · `routes/`
- `client/` — React + Vite · `pages/` หน้าจอ · `components/` ส่วนประกอบร่วม · `styles.css` ธีม
